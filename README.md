# 🦷 Smile Dental Clinic

A fully responsive dental clinic website with a modern and professional design, built using pure HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Click here to view the website](https://asmaakh5.github.io/smile-dental--clinic/)

## ✨ Features

- Modern and fully responsive design
- Arabic interface with RTL support
- Animated statistics counter
- Interactive appointment booking form
- Floating WhatsApp button for quick contact
- Smooth scrolling between sections
- Mobile-friendly navigation menu
- Hover and scroll animations
